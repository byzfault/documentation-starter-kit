# Consultancy, Audits & Klevu

Independent work from April 2018: platform and code audits, solutions architecture and developer relations. This is the work clients brought me in for when they needed somebody who could read the system and tell them the truth about it.

## Platform and Code Audits (2018 to 2020)

Productised, fixed-fee, enterprise-grade audits for e-commerce merchants. 10 to 15 engagements, delivered autonomously and presented in person to client leadership. Clients included ME+EM, Kinetico, Big Green Egg and Madison Bikes (FreeWheel).

**What a client got:** a scored executive summary and prioritised recommendations with effort estimates, backed by full evidence:

- Solution architecture, indexer, cache and cron review
- ERP and search integrations
- Hosting and deployment (Magento Commerce Cloud, Platform.sh) and Git flow
- Database review
- Per-extension code review, graded A to F
- Functional review against the original spec, and error analysis
- Front-end and application performance (GTmetrix, WebPageTest, Lighthouse, New Relic, Blackfire)
- Redis and Varnish architecture, and server tuning
- Security: OWASP Top 10, malware scans and a core diff
- Upgrade gap analysis and vendor-transition runbooks

**Where the value was.** Judgment over tool output. I called the false positives, found root causes and made the architectural calls. See [Case Studies](/case-studies) for examples.

## Klevu · Senior Solutions Architect and Developer Relations (2018 to 2020)

Enterprise AI-powered search SaaS, now Athos Commerce. It enriched catalogues with NLP and served them by API for natural-language and image search across Magento, BigCommerce and Shopify.

**What I did:**

- Developer relations, onboarding and documentation for the integrations: installation guides, API testing and usage docs
- Fed developer friction back into the product
- Hosted developer webinars, including a PWA session for around 50 merchants
- Worked the forums and advocated for the product
- Wrote long-form technical and marketing content on NLP, AI-generated search content and indexing

**Where my background mattered:** I had trialled Klevu as search at Folk before it became a client. I knew what a merchant's stack looks like from the inside.
