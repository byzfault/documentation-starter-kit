## Current Work: An Agentic Content Designer in Production

In late 2026 I designed an agentic content designer for a global financial services company, working with its design and content team. It reviews and rewrites the wording on product screens against the team's written standards. It is in use as v1.

- **The audit.** 166 product screens and 28 message captures reviewed. Each finding became a rule, traced to the guideline it came from
- **The skills.** 27 content skills in a versioned pack of 35, sorted by how reliably each can be applied. Eleven run as code, with no model involved
- **The orchestrator.** Detectors read the same frozen original in parallel. One precedence table settles conflicts. One writer edits each screen once. The mechanical rules run in code, last
- **The evals.** Facts are guarded in layers, and a grader that has not seen the writer's work scores every run against a rubric

The client is under NDA, so the case study names no company or product. The client's content designer also wrote orchestrator code.
