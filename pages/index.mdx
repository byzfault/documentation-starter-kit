## Current Work: Agentic Content Review at Mastercard

Recent work at Mastercard includes an AI content-review system I designed and built with the design and content team for MDES Manager. MDES Manager is the web application card issuers use to configure cards for Apple Pay, Google Pay and Samsung Pay. The system checks interface copy against the team's written standards.

- **The audit.** I audited 166 product screens and 28 message captures. Each finding became a rule, traced to the guideline it came from
- **The skills.** A library of AI review skills: 27 delivered in a versioned bundle, about 75 defined. Each one runs in Figma's AI agent and in Claude Code
- **The orchestrator.** Detectors run in parallel on the same frozen text. One precedence table settles conflicts. Mechanical rules run in code, after the model. Facts are guarded twice. A separate grader scores the result against a rubric
- **The evals.** A harness that repeats the client's own tests flow by flow, with traces, so my results sit beside theirs

This is a proof of concept with light testing. It is not in production and I claim no measured saving. The client's content designer contributed code to the orchestrator.
