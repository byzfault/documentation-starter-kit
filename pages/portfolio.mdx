    problem="Stablecoin supply data is spread across issuers and chains. Most of what gets published is one headline number, which tells you nothing about where the supply actually sits or which chain moved."
    approach="A static dashboard tracking supply by chain and issuer, focused on Ethereum, Tron and Solana across eight tracked chains.   <ProjectCard
    title="Solana Wallet Finder"
    status="build"
    kicker="Wallet analysis · 2026"
    problem="Working out which Solana wallets are worth watching means cross-referencing token buyers by hand. The useful question, which wallets bought all of these tokens and which of them are actually any good, has no cheap answer."
    approach="A local toolkit sharing one server, one cache and one API budget. Triangulate takes two to five tokens and returns the wallets that bought all of them, ranked. Copy Tracker takes a profitable wallet and works out who it is following. A usage view keeps the API spend visible, because the budget is the real constraint on this kind of tool."
