## Autonomous On-Chain Trading Agent

A 24/7 signal and execution system in Bun and TypeScript, with Postgres, Helius, Birdeye and CoinGecko APIs and a Telegram operations interface.

**Design:** every LLM call routes through a central gateway with an earned-authority ladder. The model advises and vetoes. Deterministic code executes. Every verdict is logged and graded.

**Why it is here:** it is accountable AI in practice. The same idea applies to any team putting an LLM near a consequential decision.

## Stablecoin Flow Dashboard

A public view of stablecoin flows across Tron, Ethereum and Solana, built from on-chain data. Labelled venue proxies give corridor-level views.

**Result:** it drew engagement from payments executives on LinkedIn.

## Solana Wallet Finder

A web UI that takes one to five Solana token addresses and returns the wallets that bought all of them, ranked by realised PnL.

**Why it is here:** it is real wallet tracing and attribution work.

## On-Chain Background

Active on-chain since 2017 across Ethereum and Solana: DeFi, wallets, bridges and developer tooling. Analysis with GMGN, Cielo, Solscan and Bubblemaps.
