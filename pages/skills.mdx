# Skills & Expertise


## Documentation Platforms

I specialize in modern documentation-as-code workflows, with deep expertise in **AsciiDoc**, **Docusaurus**, and **GitBook**. My approach treats documentation with the same rigor as production code—version controlled, peer reviewed, and continuously deployed.

With **AsciiDoc**, I create sophisticated technical documentation that scales from single-page guides to enterprise documentation suites. **Docusaurus** is my platform of choice for developer-focused documentation sites. I build interactive experiences using MDX components, implement versioned API documentation, and customize React-based themes to create documentation that developers actually want to use. Every site I build prioritizes performance, searchability, and mobile responsiveness.

For collaborative documentation needs, I deploy **GitBook** to enable teams to contribute without deep technical knowledge, while maintaining Git-based version control and automated publishing workflows behind the scenes.
